# Claim Guardrails

## Use

- human-supervised pre-submission readiness agent
- source-verifiable evidence
- configured synthetic readiness policy
- deterministic source-fidelity verification
- deterministic policy execution over source-linked assertions
- three-valued readiness logic
- content-addressed evaluation record
- reproducible execution evidence
- separate human-review Task
- designed to measure in a pilot

## Avoid

- guarantees payer approval
- autonomous PA approval or denial
- live payer submission
- eliminates hallucinations
- zero-error or zero-hallucination system
- verifies clinical truth
- immutable or unalterable ledger
- audit-proof compliance
- measured time savings before a pilot
- real payer policy coverage when using the synthetic fixture

## Required spoken boundary

> The verifier confirms source fidelity, not clinical truth. The policy is synthetic, extraction is mocked for the demo, and a human remains responsible for the reviewed outcome.
